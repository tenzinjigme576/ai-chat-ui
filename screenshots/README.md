# Screenshots

Add exported PNGs from Figma here for GitHub preview:

1. Open [the Figma file](https://www.figma.com/design/o9THnW4EMHsg19KGhIdKWK)
2. Go to **Final UI**
3. Select each screen → **Export** → PNG @ 2x
4. Name files:
   - `01-welcome.png`
   - `02-main-chat.png`
   - `03-suggestions.png`
   - `04-settings.png`
   - `05-voice.png`

Then commit: `git add screenshots && git commit -m "Add screen exports"`
